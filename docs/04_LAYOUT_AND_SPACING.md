# Budget Planner Desktop
# Layout & Spacing System v2.0

This document defines the spatial language of the application.

Layout should feel intentional.

Whitespace is a feature.

Never attempt to "fill empty space."

--------------------------------------------------
SPACING PHILOSOPHY
--------------------------------------------------

Spacing creates hierarchy.

Users should understand the page simply by looking at the spacing.

Information that belongs together sits close.

Information that does not belong together is separated generously.

Never make everything equally spaced.

--------------------------------------------------
ALIGNMENT RULES
--------------------------------------------------

Everything aligns.

Cards align.

Titles align.

Charts align.

Buttons align.

Nothing should appear "almost aligned."

--------------------------------------------------
PROPORTION RULES
--------------------------------------------------

Large information occupies large space.

Small information occupies small space.

Whitespace is never wasted.

Whitespace creates luxury.

--------------------------------------------------
FINAL RULE
--------------------------------------------------

The layout should resemble a premium desktop application rather than a web dashboard.

When uncertain between adding another card or using whitespace,

choose whitespace.
