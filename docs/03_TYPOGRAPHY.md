# Budget Planner Desktop
# Typography System v2.0

This document defines every typography rule in the application.

Typography is the primary source of hierarchy.

Not color.

Not borders.

Not shadows.

If typography is correct, the interface becomes dramatically easier to understand.

Examples

₦12,450

₦1,200,000

450000

NGN450000

₦450000

Thousands separators

---

# VISUAL RHYTHM

Typography should follow:

Large

↓

Medium

↓

Small

↓

Muted

Every component should clearly communicate:

What is most important.

What is supporting information.

What is metadata.

Nothing should compete with the primary metric.

---

# TYPOGRAPHY RULES

Never use more than four text sizes inside one card.

Never bold everything.

Never center-align dashboard metrics.

Never mix unrelated font weights.

Whitespace creates hierarchy.

Not bold text.

The user should be able to understand every screen in less than three seconds simply by scanning the typography hierarchy.
