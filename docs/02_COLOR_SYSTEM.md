# Budget Planner Desktop
# Color System v2.0

This document defines the complete color language of the application.

These colors are mandatory.

No component may introduce a new color unless explicitly documented here.

---

# DESIGN GOAL

The application should feel:

• Premium
• Calm
• Financial
• Trustworthy
• Modern

It should never feel:

• Corporate
• Neon
• Gaming
• Material Design
• Bootstrap

The interface should remain bright, airy and elegant.

# COLOR RULES

Use color intentionally.

If a color does not communicate meaning,

remove it.

Neutral surfaces should dominate.

Accent colors should attract attention.

The application should be approximately:

80% neutral

15% accent

5% semantic colors

This balance creates a premium financial application.
